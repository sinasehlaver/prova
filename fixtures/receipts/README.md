# Receipt fixtures — SYNTHETIC

These PDFs are generated by `scripts/make-receipt-fixtures.mjs` (`node scripts/make-receipt-fixtures.mjs`). They imitate the
wording and amount formats of Papara / Enpara / Ziraat / İş Bankası / Yapı Kredi receipts, but they are **not real dekonts**:
plain Helvetica text layer, no bank layout, fonts, images or line-wrap quirks. `scanned-no-text.pdf` has no text layer (unreadable case).

Passing them proves the parser logic, not the real-world hit-rate. **Real, redacted dekont PDFs from members' banks are still needed**
(3-5, incl. one image-only). Drop them here and add cases to `server/receipt.test.mjs`. Never commit unredacted ones (names, IBANs).
